# Mini 3D Explorer - Midterm Project

## Project Description
Mini 3D Explorer is a small interactive 3D game built using C# and OpenTK.  
The player can move around a simple 3D environment, interact with objects, and experience basic lighting and textures.

---

## Gameplay Instructions
- **W / A / S / D** → Move forward / left / backward / right  
- **Mouse** → Look around  
- **E** → Toggle the lamp light (if near the lamp)  
- **F** → Collect the gem (if near the gem)  
- **Esc** → Grab/release the mouse cursor

---

## Features Implemented
- Rendering of multiple 3D objects (cube props, floor plane, gem)  
- Functional camera with keyboard + mouse control  
- Phong lighting with ambient, diffuse, and specular components  
- Textured environment using PNG/JPG images  
- Basic object interaction (toggle lamp, collect gem)  
- Organized codebase with classes for Shader, Mesh, Texture, and Camera
